# Historical workflows (optional)

- `fluodb/`: research scripts for the earlier large-scale FluoDB observational analysis. Requires downloading original FluoDB and user-specific setup. Results have not been regenerated as part of this release. See its own README.
- `huckel/`: self-contained idealized tight-binding sign-rule reproduction. The model script can run without FluoDB.
- `cyanine_identity/`: exploratory FluoDB screening scripts and acknowledged identity-classification caveats.

The repo's primary verified scientific deliverable is the four-trace-pair raw-spectrum analysis, under `src/xanpy_cyanine/`, `results/`, `figures/`, and `docs/RESULTS.md`.
